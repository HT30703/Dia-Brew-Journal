# Brew Journal

A fast, private coffee brew log — record beans, gear, recipe, and a cupping-based /10 score, then repeat what works.

Runs entirely in the browser. Your data is stored locally on each device (no server, no accounts). Use **Backup & Restore** in the menu to move data between devices.

## Features
- Log bean, roaster, region, roast date (with live "days off roast"), equipment, and recipe
- Linked dose / water / ratio with a 1:15 default
- Six-element cupping rating that auto-averages into a /10 score
- Menu-based history grouped by bean, region, brewer, drip assist, and grinder
- "Same as last time" defaults + a bean library so daily logging takes seconds
- Built-in brew timer
- Installable to your phone's home screen, works offline

## Run it
Open `index.html` — that's it. Hosted free on GitHub Pages.

## Add to your phone
Open the site in Safari (iPhone) or Chrome (Android) → Share / menu → **Add to Home Screen**.
